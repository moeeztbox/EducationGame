# Education Game

Educational drag-and-drop games for students (subjects, chapters, games).

## Structure
- `frontend/` - React app (Vite). Kept as a plain web app so it can be wrapped with Electron later.
- `reference/` - `skeleton-game.html`: standalone HTML demo of the skeleton matching game (to be ported to React).

## Run
```bash
cd frontend
npm install
npm run dev
```
